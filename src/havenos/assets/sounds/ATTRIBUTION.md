# Sound attribution

The audio files in this folder are from the **Home Assistant Voice Preview Edition** firmware, commit `d4e6fa4`
(https://github.com/esphome/home-assistant-voice-pe/tree/d4e6fa4/sounds), unmodified:

[Home Assistant Voice Preview Edition Sounds](https://github.com/esphome/home-assistant-voice-pe/tree/dev/sounds) © 2024 by
[Clayton Charles Tapp](https://www.cctaudio.com/) is licensed under
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

| File | Used for |
|---|---|
| `wake_word_triggered.flac` | the chime after the wake word |
| `timer_finished.flac` | a ringing timer (repeats with a 500 ms gap) |
| `mute_switch_on.flac`, `mute_switch_off.flac` | muting and unmuting the microphone |
| `error_cloud_expired.mp3` | a spoken message for the `cloud-auth-failed` pipeline error |

`LICENSE.md` is the licence notice that ships with them upstream. Only the sounds the voice code uses were copied;
the upstream folder has more.
